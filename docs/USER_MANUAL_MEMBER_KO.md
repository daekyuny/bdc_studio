## 시작하기

### 로그인 방법

**Google 계정으로 로그인**
**Google로 로그인** 버튼을 클릭하면 Google 계정 선택 화면이 열립니다. 구글 계정을 선택하면 자동으로 로그인됩니다.

**이메일 / 비밀번호로 로그인**
이메일과 비밀번호를 입력한 후 **로그인** 버튼을 클릭하거나 Enter를 누릅니다.

> **참고:** 계정은 PM(프로덕트 매니저)이 미리 등록하거나 초대 링크를 통해 만들어집니다. 직접 회원가입 기능은 없습니다.

### 프로필 편집

로그인 후 화면 상단의 이름 또는 아바타를 클릭하면 프로필을 편집할 수 있습니다.

- **표시 이름** 및 **전화번호** 수정
- **아바타 사진** 업로드 (최대 5 MB). 삭제하면 이니셜로 표시됩니다.
- **비밀번호 변경** (Google 계정이 아닌 경우만) — 현재 비밀번호가 필요합니다.

## 팀 선택 화면

로그인하면 팀 선택 화면으로 이동합니다.

- **팀 카드**에 팀 이름과 멤버 아바타가 표시됩니다. 카드를 클릭하면 해당 팀의 스프린트 뷰로 들어갑니다.
- 멤버 아바타를 클릭하면 해당 멤버의 전체 프로필 사진을 볼 수 있습니다.
- 속한 팀이 1개 밖에 없을 경우 팀 카드는 하나밖에 보이지 않습니다.

## 스프린트 뷰

팀 카드를 선택하면 스프린트 뷰로 진입합니다. 태스크 업데이트, 차트 조회, 백로그 관리가 모두 여기서 이루어집니다.

### 스프린트 사이드바

왼쪽 패널에 해당 팀의 모든 스프린트가 목록으로 표시됩니다. 클릭하면 해당 스프린트로 전환됩니다.

### 헤더 및 툴바

**프로젝트 오늘(TODAY)**
툴바 중앙에 표시되는 날짜로, 모든 작업 기록의 기준 날짜입니다.

- 페이지를 열 때마다 실제 오늘 날짜로 자동 초기화됩니다.
- 날짜를 클릭하면 직접 변경할 수 있습니다 (근무일만 선택 가능).
- 태스크의 작업량/잔여량을 기록할 때 이 날짜가 기준이 됩니다.

### 통계 카드

현재 스프린트의 요약 정보가 실시간으로 표시됩니다.

| 항목 | 의미 |
|---|---|
| 기간 | 스프린트 시작·종료 날짜 및 총 일수 |
| 근무일 | 공휴일을 제외한 평일 수 |
| 총 포인트 | 스프린트 태스크 추정치의 합계 |
| 잔여 | 현재 남은 작업량의 합계 |
| 완료 태스크 | 완료된 태스크 수 |
| 가용 일수 | 팀 전체 작업 가능 용량 |
| 진행률 | 전체 대비 완료된 작업 비율 (진행 바 포함) |

### 번다운 차트

스프린트 진행 상황을 시각화한 SVG 차트입니다.

| 선 | 색상 | 의미 |
|---|---|---|
| 이상선 (Ideal) | 파란 점선 | 이상적인 선형 감소 목표선 |
| 실제선 (Actual) | 빨간 실선 | 실제 일별 잔여 작업량 |
| 범위선 (Scope) | 회색 | 스프린트 계획 총량 (중간에 태스크가 추가/제거되면 변동) |

**차트 조작:**
- **X축 날짜 레이블 클릭**: 해당 날짜의 과거 태스크 상태를 볼 수 있습니다 (브라우즈 모드). 같은 날짜를 다시 클릭하면 현재 상태로 돌아옵니다.
- **일수 표시** 체크박스: 날짜 아래에 스프린트 몇 일차인지 표시합니다.

### 태스크 테이블

현재 스프린트의 태스크 목록입니다.

**컬럼 설명:**

| 컬럼 | 설명 |
|---|---|
| ID | 태스크 식별자 (예: `0.1.2`) |
| 태스크 | 태스크 이름. 마우스를 올리면 연결된 스토리 설명이 표시됩니다. |
| 실제/추정 | `작업량 + 잔여량 / 추정치` |
| 작업량 | 지금까지 작업한 시간/일 |
| 잔여량 | 아직 남은 시간/일 |
| 상태 | Todo / In Progress / Done (자동 변경) |
| 완료일 | 잔여량이 0이 됐을 때 자동 기록 |
| 액션 | 업데이트, 제거, 이동, 분할 버튼 |

**진행 기록 방법:**

1. 담당 태스크의 **업데이트** 버튼을 클릭합니다.
2. 담당자가 지정되지 않은 경우 팀원 선택 화면이 표시됩니다.
3. **작업량** (오늘 작업한 양)과 **잔여량** (아직 남은 양)을 입력합니다.
4. Enter를 누르거나 **저장**을 클릭합니다.

태스크 상태는 자동으로 변경됩니다:
- 잔여량 = 0 → **Done** ✓
- 작업량 > 0이고 잔여량 > 0 → **In Progress**
- 작업량 = 0 → **Todo**

**스프린트 마지막 날 액션:**

스프린트 종료일에는 미완료 태스크에 추가 버튼이 표시됩니다.

| 버튼 | 동작 |
|---|---|
| 이동 | 이 태스크를 다른 스프린트로 옮깁니다. |
| 분할 | 현재 태스크를 완료 처리하고, 남은 작업량을 다른 스프린트에 새 태스크로 만듭니다. |

**정렬 및 순서 변경:**
- 컬럼 헤더를 클릭하면 해당 컬럼 기준으로 정렬됩니다.
- 정렬되지 않은 상태에서 ⠿ 핸들을 드래그하면 행 순서를 수동으로 바꿀 수 있습니다.

### 백로그 패널

태스크 테이블 아래의 접을 수 있는 패널입니다. 아직 이번 스프린트에 포함되지 않은 백로그 태스크가 표시됩니다.

- **행을 드래그**하여 태스크 테이블 위에 놓으면 스프린트에 추가됩니다.
- **ID로 추가**: 태스크 ID(예: `0.1.1`)를 입력하고 **추가**를 클릭하거나 Enter를 누릅니다.

## 백로그 탭

백로그는 팀의 전체 작업 목록을 **스토리 → 태스크** 구조로 관리하는 공간입니다.

### 구조

- **스토리**: 사용자 스토리 단위. ID(예: `0.1`), 설명, 우선순위를 가집니다.
- **태스크**: 스토리 하위 작업. ID는 `스토리ID.번호` 형식(예: `0.1.2`)이며, 설명, 추정치(일), 담당자 목록을 가집니다.

### 스토리 조작

| 동작 | 방법 |
|---|---|
| 스토리 추가 | **스토리 추가** 클릭 |
| 스토리 편집 | 스토리 행의 **편집** 클릭 |
| 스토리 삭제 | 편집 모드에서 **삭제** 클릭 (하위 태스크 전체 삭제됨) |
| 펼치기/접기 | 스토리 행의 ▼/▶ 클릭 |
| 전체 펼치기/접기 | 테이블 위 버튼 클릭 |

### 태스크 조작

| 동작 | 방법 |
|---|---|
| 태스크 추가 | 스토리의 **태스크 추가** 클릭 (편집 모드) |
| 태스크 편집 | 태스크 행의 **편집** 클릭 |
| 태스크 삭제 | 편집 모드에서 **삭제** 클릭 |
| 담당자 지정 | 담당자 필드 클릭 → 체크박스로 팀원 선택 |

### 엑셀 가져오기 / 내보내기

- **엑셀에서 가져오기**: Story ID, User Stories, Priority, Task ID, Description, Est. Days, Assigned To 컬럼이 있는 `.xlsx`/`.xls` 파일을 업로드합니다.
- **엑셀로 내보내기**: 현재 백로그를 `.xlsx` 파일로 다운로드합니다.

## 주요 워크플로우

### 매일 작업 기록하기

1. 페이지를 열면 TODAY가 오늘 날짜로 자동 설정됩니다.
2. 담당 태스크의 **업데이트** 버튼을 클릭합니다.
3. 오늘 작업한 양(**작업량**)과 앞으로 남은 양(**잔여량**)을 입력합니다.
4. **저장**하면 번다운 차트가 즉시 업데이트됩니다.

### 과거 진행 상황 확인하기

1. 번다운 차트의 날짜 레이블을 클릭합니다.
2. 태스크 테이블이 해당 날짜의 상태로 전환됩니다.
3. 같은 날짜를 다시 클릭하면 현재 상태로 돌아옵니다.

### 나의 메모 사용하기

**⚙** (설정) 버튼 → **나의 메모** 탭에서 본인만 볼 수 있는 개인 메모를 작성할 수 있습니다.
`**굵게**`, `*기울임*`, `` `코드` ``, `# 제목`, `- 목록` 마크다운 문법을 지원하며, 작성 후 자동 저장됩니다.

### 스프린트 마지막 날 처리하기

스프린트 종료일에 미완료 태스크가 있다면:

- **완료된 경우**: 업데이트에서 잔여량을 0으로 입력하면 자동으로 Done 처리됩니다.
- **다음 스프린트로 넘길 경우**: **이동** 버튼으로 다음 스프린트를 선택합니다.
- **일부만 완료된 경우**: **분할** 버튼을 사용하면 현재 태스크가 Done 처리되고, 남은 작업이 다음 스프린트에 새 태스크로 생성됩니다.
