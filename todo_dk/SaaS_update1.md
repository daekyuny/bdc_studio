# SaaS-like update step 1

purpose: will make the BS(Burndown Studio) more SaaS like.
This is Step 1 update

## Structure

### Group

- Analogous to 'tenent' in general SaaS.
- So this is the unit BS handles as a tenent, which means later SM can monitor Group activity such as number of members/teams, storage usages etc. This will be the bases of billing.
- A Group is managed by PM.
- So now PM's main screen is Group screen.
- Group has a name which can be updated by PM
- In PM's main screen(when login as PM) Group Name is displayed.
- Default group name is PM name + "Group", but the team profile can be changed in the PM's main screen. 
- PM can manage only 'ONE' group.
- PM can create/delete/manage Teams. (Done)
- PM can assign members in this Group to any Teams (Done)

### Members

- Members are now associated with Groups.
- In that group, member can be assigned to teams by PM. (Done)
